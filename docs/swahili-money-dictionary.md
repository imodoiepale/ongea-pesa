## Greetings & Conversation Openers

Users may open a voice session with these phrases before stating their request:

**niaje** — hey / what's up — informal Nairobi greeting ("Niaje, tuma elfu mbili kwa John")
**mambo** — what's up / how are things — casual opener ("Mambo, niambie balance yangu")
**mambo vipi** — how are things — greeting before a request
**sema** — speak / go ahead / what is it — prompt to state request ("Sema, unataka nini?")
**oya** — okay / hey / used to get attention — filler before a command ("Oya, tuma 500 kwa Mary")
**eeh** — yes / affirmative — agreement filler
**hujambo** — formal greeting (hello, how are you) — polite opener
**habari** — formal greeting (how are you / news) — polite
**poa** — cool / fine / good — acknowledgement; also used to confirm ("Poa, sawa")
**safi** — clean / cool / perfect — strong affirmation ("Safi kabisa!")
**fresh** — great / excellent — Sheng affirmation
**fiti** — fit / okay / all good — Sheng for everything is fine
**rada** — understood / clear — Sheng acknowledgement
**fasta** — fast / hurry up — variation of "haraka"

### Sheng Number Slang
**ngiri / ngwanye / nge** — 1,000 (one thousand) — core Sheng; "ngiri tano" = 5,000
**ketheng / keth** — 1,000 (one thousand) — Sheng variant common in Eastlands
**finje** — 50 (fifty) — "finje mbili" = 100

**bob** — 1 shilling / generic small coin — "kama bob mia" = about 100 shillings

### Amount Modifiers
**kiasi** — amount / quantity ("kiasi gani?" = how much?)
**bei** — price / rate / amount ("bei yake ni ngapi?" = what is the price?)
**nusu** — half ("nusu ya elfu mbili" = 1,000)
**robo** — quarter ("robo ya elfu" = 250)
**zaidi** — more / extra ("zaidi ya elfu tano" = more than 5,000)
**chini ya** — less than ("chini ya mia tano" = less than 500)
**juu ya** — above / more than
**hasa** — exactly ("hasa elfu tano" = exactly 5,000)
**karibu** — approximately / near ("karibu elfu" = about 1,000)
**kama** — approximately / like ("kama mia tatu" = around 300)

### Number Pronunciation Rules
When Kenyans say amounts, they typically mix English and Kiswahili:
- "thirty five thousand" = "thelathini na tano elfu" (Swahili) or just "thirty five k" (English/Sheng)
- "one fifty" = 150 shillings
- "two k" = 2,000 shillings
- "five hundred bob" = 500 shillings
- "ten k" = 10,000 shillings
- "a hundred k" = 100,000 shillings
- Numbers above 1,000 are often stated in thousands: "two fifty" can mean 250 OR 2,500 depending on context — always confirm if ambiguous

## Contextual Notes for the Agent

1. **"Tuma kwa mama / baba"** — The user is likely sending to a parent. Ask for their phone number or registered name on Ongea Pesa.

2. **"Lipa bili"** — Generic "pay bill" — follow up with which bill (umeme/maji/ada/kodi) and account number.

3. **"Weka kwa chama"** — Deposit to chama — route to chama contribution flow.

4. **"Toa" alone** — Ambiguous: could mean withdraw cash OR take from savings. Clarify: "Withdraw cash to M-Pesa or take from a specific wallet/account?"

5. **"Angalia" alone** — Usually means check balance. Respond with current wallet balance.

6. **Mixed amounts**: Users may say "elfu tatu na mia tano" (3,500), "ngiri mbili na nusu" (2,500), or "soo saba" (700). Parse compound amounts correctly.

7. **"Boss / msee"** when addressing the agent — this is normal and friendly; do not interpret as a name.

8. **"Haraka haraka" or "sasa sasa"** — User is urgent; proceed quickly without extra clarification if all required fields are already present.

9. **"Rudia" or "fanya tena"** — Repeat the last transaction or action, not just the verbal response.

10. **"Kama / karibu [amount]"** — Approximate amounts; confirm the exact figure before transacting.
