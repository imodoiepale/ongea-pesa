## Order of execution (start here)

1. **Legal shield first** (07): register KECOBO copyright (~KES 1,000, days), file KIPI TM27 trademark search then TM2 application, register with ODPC as data controller. Cheap, fast, and protects everything else.
2. **Security** (08): run the audit checklist; fix criticals before any public noise.
3. **Brand lock** (01): confirm taglines, colors, founder story — everything downstream quotes it.
4. **Investor material** (06): deck + one-pager ready before outreach creates inbound interest.
5. **Content engine** (03 + 05): shoot the first 10 videos in one weekend using the location list.
6. **Outreach** (04): influencers + accessibility orgs + press, using the templates.
7. **Track** (10): weekly against the roadmap.
